# GLASYPAY

GLASYPAY is an Android-first digital wallet and payment platform project.

## Project status

This repository is being prepared as a development scaffold. It is not production-ready yet.

## Planned components

- Android application: Kotlin and Jetpack Compose
- Backend API: Laravel/PHP
- Admin dashboard: Next.js and TypeScript
- Cloudflare Workers API and D1 database schema
- Payment-provider adapters for Midtrans, Xendit, and Tripay (disabled until credentials and provider verification are configured)

## Important

Do not use this project to process real payments or store real customer funds until authentication, authorization, ledger integrity, webhook verification, security review, testing, and deployment configuration are complete.
