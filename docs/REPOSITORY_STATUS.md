# Repository status

The GLASYPAY development scaffold is being published to this repository. The repository currently contains the project README and selected source/configuration files. Publication is not the same as deployment: Cloudflare D1 has not been migrated remotely, the Worker has not been deployed, and no Android APK or production dashboard build has been verified.

Payment provider adapters are placeholders and disabled. Do not process real funds or enter production credentials until authentication, ledger posting, provider API integration, webhook signature verification, reconciliation, compliance review, and security testing are complete.
